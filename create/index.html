CREATE ／ 設計図

部屋は3つでいい。
増やすのは、人が来てから。

サーバーの作り方で最初に間違えるのは、部屋を作りすぎることです。10人のサーバーに部屋が15個あれば、全部が無人に見えます。ここでは宣伝を始められる状態までを、5工程で作ります。

サーバーを作る

入った直後に見える部屋に、ルールと「何のサーバーか」の1行を置きます。ここが空だと数秒で抜けられます。

01サーバーの作り方

作る前に決めること

決めるのは「何をする場所か」の1行だけです。これが決まっていないと、部屋の名前もルールも決まりません。逆にここさえ決まれば、あとは10分で作れます。

テンプレートを使わない理由

Discordにはサーバーテンプレートがありますが、部屋が多く作られることがあります。人数が少ないうちは、それが全部「無人の部屋」に見えます。自分で3つ作るほうが早く、後から自由に変えられます。

02最初に作る部屋

3つだけ作る

  • ルール——禁止事項3つと、何のサーバーかの1行
  • 雑談——何でも書ける場所。ここが本体
  • 自己紹介——書かなくてもいい場所として置く

部屋を増やしすぎるとどうなるか

10人のサーバーに部屋が15個あれば、全部が無人に見えます。会話が薄く広がるからです。逆に3つなら、同じ10人でも常に何かが動いて見えます。部屋は人数が増えてから足してください。

構成図（完成形）

人が増えてきた時の形です。最初からこれを作らないでください。★が付いているものだけを先に作ります。

SERVER STRUCTURE ／ 構成図

▸ はじめに
#ルール★最初に #お知らせ #自己紹介★最初に
▸ はなす
#雑談★最初に #質問 🔊通話
▸ ジャンル別（人が増えてから）
#〈ジャンル1〉 #〈ジャンル2〉 #募集
▸ 運営（必要になったら）
#運営用 #通報 #ログ
部屋を増やす前に、通り道を1本入った人が最初にどこへ行くか。そこが決まっていないサーバーは、人数が増えても静かなままです。

03入口の作り方

最初の3秒で決まる

宣伝で人が来ても、入った直後に何も無ければ数秒で抜けられます。宣伝の効果が出ない原因の多くは、宣伝ではなくここにあります。

入口に置くもの

  1. 何のサーバーか——1行。紹介文と同じ内容でいい
  2. 禁止事項3つ——多いと読まれません
  3. どこで話せばいいか——「まずは #雑談 へ」の一言

この3つだけで、離脱は目に見えて減ります。凝った案内画像より、この3行のほうが効きます。

04おすすめ設定と権限

@everyoneから外す権限

権限 外す理由
チャンネルの管理 部屋を消される・作られる。荒らしの主な手口です
メンバーの管理（キック・BAN） 他の人を追い出せてしまいます
@everyone のメンション 全員に通知を飛ばせます。最も嫌がられる荒らし
ロールの管理 自分に権限を付けられてしまいます

ここを外しておくだけで、荒らしの被害はかなり小さくなります。Botを入れるより先に、この設定です。詳しくは荒らし対策で書いています。

通知の初期設定

サーバーの通知設定は「@メンションのみ」にしておくのが無難です。全メッセージ通知が初期値だと、入った人が通知の多さで抜けます。

コミュニティ機能は後で

コミュニティ機能を有効にすると、ルール画面やオンボーディングが使えます。ただし設定項目が一気に増えます。人が来るところまで進めてから検討してください。

05作った後にやること

サーバーは作っただけでは誰にも見つかりません。Discordには「新しいサーバーを一覧で見せる」仕組みがほとんど無いためです。

  1. 紹介文を3行で書く——何の／誰向け／何がある
  2. 貼れる場所に貼る——宣伝サーバーと一覧サイトの両方へ
  3. 足りない役割は募集で埋める
  4. 来た人が残るようにする

FAQよくある質問

ディスコードのサーバーの作り方を教えてください。

Discordの左側にある＋からサーバーを作成し、部屋をルール・雑談・自己紹介の3つだけ作ります。入口にルールと案内を置き、@everyoneの権限を絞ってから、期限なしの招待リンクを発行します。ここまでで宣伝を始められます。

最初にいくつ部屋を作ればいいですか？

3つで十分です。ルール・雑談・自己紹介から始めてください。人数が少ないうちに部屋を増やすと、会話が薄く広がってどこも無人に見えます。必要になってから足すほうが常に賑わって見えます。

サーバーテンプレートは使ったほうがいいですか？

使わなくて構いません。テンプレートは部屋が多く作られることがあり、人数が少ないうちは過疎に見える原因になります。自分で3つ作るほうが早く、後から自由に変えられます。

おすすめの設定はありますか？

@everyoneからチャンネル管理・メンバー管理・メンション全体などの権限を外すこと、招待リンクを期限なしにすること、入った直後に見える部屋を1つに絞ることの3つです。

コミュニティ機能は有効にしたほうがいいですか？

人数が増えてからで構いません。有効にするとルール画面やオンボーディングが使えますが、設定項目が増えます。まず人が来るところまで進めてから検討してください。

作ったのに人が来ません。

サーバーは作っただけでは誰にも見つかりません。宣伝サーバーやサーバー一覧サイトへ貼る必要があります。貼れる場所と書き方は宣伝のページで解説しています。
